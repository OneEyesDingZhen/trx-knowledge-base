# 高并发高可用认知手册

> 写给"3 年前端转全栈、在做财务系统、准备跳槽"的工程师：一套**面试八股 + 架构认知地图**。
> 这是认知层读物，不是操作教程——目标是建立心智模型、讲清 trade-off、扛住面试追问，而不是教你敲命令。

## 为什么写这本

后端面试里，高并发高可用题是没有实操经验者最大的短板：缓存三问、MQ 幂等、CAP、熔断限流，题题都在追问"你们线上怎么做的"。这套知识有个残酷的性质——**没有真实流量就没法亲手练**，个人项目 QPS 个位数，硬编一段"百万级秒杀经验"反而会在追问下露馅；但不准备又不行，因为这恰好是中厂全栈岗筛人的标准题库。所以策略是分开两层：先用这本手册把认知地图建起来，能讲清每个方案解决什么问题、代价是什么、什么时候不用它——这部分纯靠阅读就能做到位，而且"讲清取舍"正是面试官真正想听的东西，比背诵参数配置高一个段位；真正的"生存技能"（调参数、压测、线上救火）留到入职后有真实流量时再实操突破，那时有监控、有告警、有老同事带，成长速度远非现在闭门造车可比。一句话：**面试赢的是认知，入职赢的是手感**，这本手册管前者，也替你规划好了后者。

这本手册的自我约束：每个概念必须回答三件事——解决什么问题、代价是什么、什么时候用或不用；禁止"视情况而定"式的空话，所有判断都给出具体维度；代码只保留概念性示例，篇幅压在全文的十分之一以内。

## 三条阅读路线

**面试冲刺路线（2-3 天）**：00 → 01 → 03 → 10 → 02 → 各篇末尾的「面试视角」小节串读 → 用《附录-面试速查QA》40 题自测查漏，答不出的回正文重读。只看第一档 + 每篇 TL;DR，其余跳过。每篇读完必须能不看稿回答三道题：它解决什么问题、代价是什么、面试官追问一层我接什么。

**系统学习路线（2 周）**：按编号 00 → 13 顺序，每天一篇。当天读完用自己的话向"空气面试官"复述一遍 TL;DR，讲不出来的回去重读对应小节。两周后应该能徒手画出整张地图：流量从入口进来，每一层有哪些手段、各自防什么。

**碎片时间路线（摸鱼读）**：按第三档 → 第二档 → 第一档顺序，先易后难。泛读篇当杂志翻，三五分钟一节也能有收获；第一档留整块时间精读，因为它们是面试真正会被连环追问的部分，值得在安静的时间里读透。

## 与配套专题的关系

本手册是**地图**，配套的「幂等与事务一致性专题」是**深潜区**。第 03 篇的消费端幂等、第 10 篇的分布式事务地图，都只是画出边界和指路牌，真正的落地方案（本地消息表、Saga、对账兜底）都收在事务专题里。为什么这么分工：高并发高可用的知识点面广但每点深度有限，靠阅读足以覆盖；而事务一致性是财务系统的立身之本，也是面试官一旦闻到你"做过钱相关的系统"就会往死里追问的方向。策略上：高并发高可用这套当杂志和八股读，后端深入能力的押注放在事务一致性上——那是面试官追问三层你还能答上来的护城河。

## 入职后的实操突破顺序

认知先行，手感后补。找到工作、有了真实流量之后，按这个顺序把地图变成肌肉记忆：

1. **缓存/Redis 实操**：把报表查询接上 Redis，亲手制造并解决一次缓存击穿，跑一次淘汰策略对比。成本最低、见效最快，也是面试话题与实操经验重合度最高的一项。
2. **MQ 实操**：把开票通知、报表刷新异步化，亲手处理一次消息堆积、写一次幂等消费者。从"能讲 MQ"到"用过 MQ"，差的就是这一回。
3. **分布式锁 + 幂等落地**：对账批处理的防重提交、单据状态机，这是财务系统的真实需求，做完你就有了可以在面试里讲三分钟的自己的故事。
4. **分库分表**：等单表真的到几千万再说，在此之前先练月度分区与冷热归档——那才是你这个量级该交的答卷。
5. **微服务治理**：最后碰。没有多团队协作就没有它的入场券，强行演练只是在学运维。

例外：**微前端**单独看——如果下家是巨石中后台、多团队共用仓库、技术栈混杂，把它跳到最前面，入职第一个月就能用上；如果下家是小团队单体前端，它对你只是一道面试题，维持第二档的投入即可，不必追加实操。

## 阅读提示

- 文中的 mermaid 图需要 GitHub、Typora 或支持 mermaid 渲染的阅读器才能正确显示；纯文本阅读器里会直接看到图源码，不影响理解正文。
- 每篇末尾的「与我的财务系统的关联」小节，是手册作者个人项目（发票 / 对账 / 多维报表，400 万级明细数据）的落地映射——有些篇目会明确说"现阶段用不上，为什么"，这个判断本身也是认知的一部分；如果你的项目量级不同，以正文给出的判断维度自行换算，不要照抄结论。
- 术语首次出现均附英文原名（如熔断器 Circuit Breaker），数据量级与技术版本以 2026 年视角为准（Redis 7.2+/8.x、qiankun 已停止主动演进、Module Federation 2.0 为现代主流）。
- 全手册共 14 篇正文 + 1 篇速查附录（40 题），总阅读量约 6 小时。它不是读完就扔的八股，建议跳槽季结束前反复回读第一档——每一次重读，你都会比上一次更能听出面试官问题背后的考察点。
