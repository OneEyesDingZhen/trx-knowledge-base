## 这套文档解决什么问题

把你从"CRUD 孤立功能开发"推向"系统构建者"——不是教你用 Vendure，而是通过吃透 Vendure 这套世界级代码库，建立可迁移到任何交易类系统（电商/供应链/财务）的设计能力。

## 推荐阅读顺序

1. **先读 01**：建立业务全景。遇到机制看不懂先放过，标记下来
2. **再读 02**：理解支撑这些业务的架构。01 里标记的"为什么"大多在这里有答案
3. **然后读 03**：合上书做方法论提炼，用自检清单和 15 道自测题验证真懂
4. **最后执行 04**：八周精读计划 + 三个渐进实验（实验三"订单对账导出插件"直接对接你的财务背景，做完就是简历素材）

如果时间紧：01 的第 3、4 章（订单状态机、资金流）+ 03 的六步法是密度最高的部分。

## 这套文档的独特视角

- **财务系统类比贯穿始终**：退款↔红冲、优惠分摊↔费用分摊、Channel↔多账簿、Collection↔报表分组——你的对账经验是学习加速器而非无关背景
- **源码级证据**：所有机制断言落到具体类名与文件路径（如 `packages/core/src/service/services/order.service.ts`），附行号（随版本漂移，以 v3.7.1 为准）
- **交叉校验过的事实**：版本漂移、许可证变更、Angular→React Dashboard 换代等易错点已统一裁决口径
- **不只讲"是什么"，更讲取舍**：如库存超卖 #3508 揭示的"正确性 vs 吞吐"权衡——系统构建者的核心判断力
