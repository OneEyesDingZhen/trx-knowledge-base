## 一、为什么有这门课

你在公司做的是财务系统的 AR/AP 模块（发票、对账、开票报表）。这套系统本质上在回答四个问题：

1. **谁欠我钱、欠多少、什么时候该还？**（应收 AR）
2. **我欠谁钱、欠多少、什么时候该付？**（应付 AP）
3. **账上的数字和银行、和客户供应商的记录对不对得上？**（对账）
4. **老板和税务要看的数字从哪来？**（报表）

财务系统不是"把 Excel 搬到屏幕上"，它背后有一套运转了 500 年的规则——**借贷记账法**。这门课先让你在真实软件里把规则跑通，再回头看你写的代码，你会发现每个字段、每张表都有存在的理由。

## 四、开始前：建库与导入数据

> Frappe Books 是**本地桌面应用**（Electron + SQLite），只能在你的电脑上运行。配套数据 CSV 请从 [arap-finance-course 仓库](https://github.com/OneEyesDingZhen/arap-finance-course) 的 `data/` 目录下载。

### 1. 启动 Frappe Books

```bash
cd vendor/frappe-books
yarn dev        # 依赖已在 node_modules 中，无需重新安装
```

### 2. 创建公司账套

首次启动进入 Setup Wizard，按以下参数建账：

| 参数 | 值 |
|------|---|
| Company Name | 基恩士自动化（上海）有限公司 |
| Country | China |
| Currency | CNY |
| Fiscal Year | 2026-01-01 至 2026-12-31 |

> 中国没有预置科目表，系统会自动套用**标准科目表**（Standard CoA），这正是我们想要的——第 2 课会带你认识它。

### 3. 导入主数据（第 2 课会详细讲，这里只列步骤）

菜单 **Import Wizard**（侧边栏 Common → Import Wizard），依次导入：

1. `data/Party.csv`（4 个客户 + 4 个供应商）
2. `data/Item.csv`（8 个产品）
3. `data/Tax.csv`（销项/进项两个 13% 税率）—— **注意**：导入 Tax 前需要先在科目表里建好 `Output Tax` 和 `Input Tax` 两个科目，第 2 课有详细步骤。

## 五、学习建议

- **顺序学习**。01 → 02 是地基，03 → 04 是核心，05 → 07 是你日常工作的主战场，08 是进阶。
- **每课必动手**。只看不练，等于看文档学游泳。
- **对着答案排查**。每课末尾有验收清单，数字对不上就回到"财务在干嘛"一节逐笔核对分录。
- **学完 08 再碰 ERPNext**。届时你有两个选择：把 ERPNext 源码 clone 到 `vendor/` 下读代码，或直接用我们课程的概念映射表对照你的工作代码。
